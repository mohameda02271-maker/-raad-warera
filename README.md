# رعد RAAD — لعبة حرب عالمية (multiplayer)

لعبة استراتيجية عربية: خريطة العالم الحقيقية، كل جندي لاعب حقيقي، دول وأقاليم وحروب وانتخابات وشركات.

## التشغيل محليًا

```
node server.js
```

يفتح على المنفذ 3000 (أو `PORT`). البيانات بتتحفظ في ملف JSON (افتراضيًا `./data.json`، غيّره بـ `DATA_FILE`).

## متغيرات البيئة

- `PORT` — المنفذ (Railway بيحدده تلقائيًا)
- `DATA_FILE` — مسار ملف حفظ العالم. على Railway خليه `/data/game.json` واربط Volume على `/data`
- `ADMIN_SECRET` — **كود المالك (إجباري عمليًا)**: العالم يفضل مقفول لحد ما أول حساب يتسجل بالكود ده، وده اللي بيبقى الأدمن نهائيًا. لو نسيت تحطه، السيرفر بيطبع كود مؤقت في اللوجز عند التشغيل.

## قواعد مهمة

- **العالم مقفول لحد ما المالك يدخل**: محدش يقدر يسجل قبل ما صاحب اللعبة يسجل أول حساب بكود `ADMIN_SECRET`. أي حد يجرب قبل كده يشوف رسالة "صاحب العالم لسه مفتحوش".
- الحد الأقصى **20 لاعب** (شامل الأدمن) — السيرفر بيرفض اللاعب رقم 21.
- كود الغش (للأدمن بس): `raad raad` — يكتبه في تاب الإدارة.

## النسخ الاحتياطي (مهم على Railway)

خطة Railway المجانية عندها رصيد شهري محدود ($1) — لو خلص، الخدمة بتقف لحد أول الشهر الجديد أو الترقية. والـ Volume التجريبي ممكن يتمسح بعد 30 يوم. عشان كده:

- من تاب **الإدارة** في اللعبة فيه زرار **"نزّل نسخة من العالم"** — بينزّل ملف `raad-world.json` فيه كل حاجة (لاعبين، دول، حروب، خزائن).
- اعمل نسخة كل فترة. لو البيانات ضاعت، ارفع السيرفر من تاني وحط الملف مكان `DATA_FILE` قبل التشغيل (أو ابعتها لي وأنا أرجّعها).

## الملفات

- `server.js` — السيرفر كامل (zero dependencies، Node 22.12+)
- `gamedata.js` + `worldpaths.json` + `neighbors.json` — خريطة العالم (SVG paths) + الحدود الحقيقية + أسماء الدول والأقاليم
- `public/` — واجهة اللعبة (HTML/CSS/JS، عربي RTL، موبايل أول)
